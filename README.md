# hemanthtejay.github.io

The root of hemanthtejay.github.io. It only does two things:

- `index.html` and `404.html` send visitors to the notes at https://hemanthtejay.github.io/hemanth.ai/
  (built from the [hemanth.ai](https://github.com/HemanthTejaY/hemanth.ai) repo).
- `robots.txt` asks AI training crawlers not to collect the site. It has to live here, at the domain root,
  to cover /hemanth.ai/ too.
